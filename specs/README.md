# Especificações do Whisper Local

Esta pasta contém somente regras e critérios de aceite do `WHISPER_LOCAL`.
Novas funcionalidades devem partir de `_modelo.md` e preservar o processamento
local, a privacidade das entradas e a separação entre código, arquivos de mídia,
saídas, modelos baixados, ambiente virtual e pacote de distribuição.

Specs de outros programas do workspace devem permanecer nas pastas desses
programas.
